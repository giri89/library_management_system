# Library Management System

A console-based Library Management System built using Java, MySQL, and JDBC.

## Features

- Add books
- View books
- Search books
- Update book copies
- Delete books
- Register members
- View members
- Issue books
- Return books
- View issued books

## Tech Stack

- Java
- MySQL
- JDBC
- Eclipse IDE

## Main Package

com.librarymanagement

## Database

Database name: library_db

Run the SQL script from:

sql/schema.sql
